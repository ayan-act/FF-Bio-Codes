## 📖 About

**FF Bio Code** is an Android application built for Free Fire players who want to discover, preview, copy, and customize stylish profile bio codes quickly.

The app brings together curated bio collections from [FFBiocodes](https://ffbiocodes.com/) in a simple, mobile-friendly experience.

It is designed to make finding and using creative Free Fire bio styles faster and easier.
